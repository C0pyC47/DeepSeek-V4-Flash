# DeepSeek-V4-Flash

Docker container for serving **DeepSeek-V4-Flash-0731** on a single **NVIDIA DGX Spark**.

## Requirements

* NVIDIA DGX Spark
* Hugging Face Hub CLI
* Docker

## Usage

```bash
git clone https://github.com/C0pyC47/DeepSeek-V4-Flash.git
cd DeepSeek-V4-Flash && make
```
